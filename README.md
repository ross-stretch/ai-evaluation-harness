# AI Evaluation Harness

AI output scoring, evaluation, rubric, review, and governance prototype.

## Problem

AI outputs need repeatable evaluation before they are used in business workflows, client deliverables, or automated systems.

## What It Does

The harness will compare AI outputs against review criteria such as:

- Accuracy
- Completeness
- Usefulness
- Tone
- Risk
- Evidence quality
- Actionability
- Human-review requirement

## Stack

Planned: Python, TypeScript, rubric JSON, review UI, structured scoring reports.

## Human Review

The harness is designed to make review easier and more consistent, not eliminate human judgment.
